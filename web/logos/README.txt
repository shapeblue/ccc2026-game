Put the official logo files in this folder. The game looks for these names
(set in web/data/game.json under "branding"; change the paths there if your
files are .svg or named differently):

  cloudstack.png      Apache CloudStack logo with the monkey
  shapeblue.png       ShapeBlue logo
  us-signal.png       linbit.png        storpool.png
  sendense.png        dimsi.png         systavo.png
  your-online.png     stack-console.png proio.png
  wesystems.png

PNG with a transparent background or SVG works best, about 200 px tall or more.
Missing files are skipped: the CloudStack and ShapeBlue slots disappear and a
partner is shown by name instead.

Use official files from each organisation's brand or press page, and follow
the ASF trademark policy for the Apache CloudStack logo.
